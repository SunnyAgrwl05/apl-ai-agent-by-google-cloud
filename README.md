# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/SunnyAgrwl05/apl-ai-agent-by-google-cloud.git
```

### Navigate to Project

```bash
cd apl-ai-agent-by-google-cloud
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

Open

```
http://localhost:5173
```
