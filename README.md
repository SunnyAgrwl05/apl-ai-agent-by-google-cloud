An AI-powered IPL assistant built using **React** and the **Gemini API** during the **Agentic Premier League (APL) AI Vibe Coding Challenge** organized by **GDG Patna**.

---

## ✨ Features

- 🎙️ Live IPL Commentary
- 🔮 Match Prediction
- 📊 Player Analysis
- 🧠 AI Strategy Advisor
- ⚡ Powered by Gemini 2.5 Flash
- 📱 Fully Responsive UI

---

## 🛠️ Tech Stack

| Category | Technology |
|----------|------------|

```bash
npm install

npm run dev
```
